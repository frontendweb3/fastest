# Review workflow

1. Read the whole template path and the relevant package/routing configuration.
2. Check required Ghost helpers and correct context scope first.
3. Check member state, content visibility messaging, comments, Portal, and search integration.
4. Check semantic structure, headings, images, keyboard use, motion, and responsive behavior.
5. Check image delivery, duplicate assets, render-blocking scripts, and unnecessary client rendering.
6. Report findings by severity with file/line, user impact, and a concrete correction. Separate confirmed faults from suggestions.
