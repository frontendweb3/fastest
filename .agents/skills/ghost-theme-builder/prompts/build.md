# Build workflow

1. Inventory templates, partials, assets, package settings, and `routes.yaml`.
2. Map each requested screen to an existing Ghost context or a justified custom route.
3. Reuse snippets and existing theme components; make the smallest coherent change.
4. Implement semantic responsive markup, then CSS, then only necessary JavaScript.
5. Test empty states, long titles, missing images, member/non-member state, keyboard navigation, and narrow viewports.
6. Run GScan and applicable build/lint commands. Report commands and results.
