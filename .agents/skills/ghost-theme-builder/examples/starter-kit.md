# Ghost Theme Starter Kit

If you prefer a more opinionated starting point with pre-configured tooling, styles, and templates, use the [Ghost Theme Starter Kit](https://github.com/frontendweb3/ghost-theme-starter-kit) instead of the minimal theme.

The starter kit includes:

- Pre-configured build tooling
- Base styles and layout
- Reusable partials and cards
- Membership and Portal integration
- SEO and accessibility defaults

Clone it and install dependencies using your preferred package manager:

```bash
git clone https://github.com/frontendweb3/ghost-theme-starter-kit.git my-theme
cd my-theme
```

**npm** — default Node.js package manager, comes with Node:

```bash
npm install
npm run dev
```

**yarn** — faster installs with deterministic lockfile:

```bash
yarn install
yarn dev
```

**pnpm** — disk-efficient with strict dependency isolation:

```bash
pnpm install
pnpm dev
```

All three produce the same result. Choose the one your project or team already uses.
