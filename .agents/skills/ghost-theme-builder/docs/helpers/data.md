---
title: Data Helpers
sidebarTitle: Overview
description: Data helpers are used to output data from your site. Use this reference list to discover what each handlebars helper can do when building a custom Ghost theme.
---

- **Tag**: [@config](/themes/helpers/data/config/), **Description**: Provides access to global data properties
- **Tag**: [@custom](/themes/helpers/data/custom/), **Description**: Provides access to custom theme settings
- **Tag**: [@page](/themes/helpers/data/page/), **Description**: Provides access to page settings
- **Tag**: [@site](/themes/helpers/data/site/), **Description**: Provides access to global settings
- **Tag**: [@member](/themes/members/#the-@member-object), **Description**: Provides access to member data
- **Tag**: [authors](/themes/helpers/data/authors/), **Description**: Outputs the post author(s)
- **Tag**: [comments](/themes/helpers/data/comments/), **Description**: Outputs Ghost's member-based commenting system
- **Tag**: [content](/themes/helpers/data/content/), **Description**: Outputs the full post content as HTML
- **Tag**: [date](/themes/helpers/data/date/), **Description**: Outputs the date in a format of your choosing
- **Tag**: [excerpt](/themes/helpers/data/excerpt/), **Description**: Outputs the custom excerpt, or the post content with HTML stripped
- **Tag**: [social\_accounts](/themes/helpers/data/social_accounts/), **Description**: Iterates the connected social accounts on a site or author
- **Tag**: [social\_url](/themes/helpers/data/social_url/), **Description**: Outputs the full URL to a social profile
- **Tag**: [img\_url](/themes/helpers/data/img_url/), **Description**: Outputs the correctly calculated URL for the provided image property
- **Tag**: [link](/themes/helpers/data/link/), **Description**: Creates links with dynamic classes
- **Tag**: [meta\_data](/themes/helpers/data/meta_data/), **Description**: Outputs structured data for SEO
- **Tag**: [navigation](/themes/helpers/data/navigation/), **Description**: Helper which outputs formatted HTML for navigation links
- **Tag**: [post](/themes/helpers/data/post/), **Description**: More `object` than helper – Contains all data for a specific post
- **Tag**: [price](/themes/helpers/data/price/), **Description**: Outputs a price with formatting options
- **Tag**: [readable\_url](/themes/helpers/data/readable_url/), **Description**: Returns a human-readable URL
- **Tag**: [recommendations](/themes/helpers/data/recommendations/), **Description**: Outputs a list of recommended sites
- **Tag**: [tags](/themes/helpers/data/tags/), **Description**: Outputs the post tags
- **Tag**: [tiers](/themes/helpers/data/tiers/), **Description**: Outputs the post tier(s)
- **Tag**: [title](/themes/helpers/data/title/), **Description**: The post title, when inside the `post` scope
- **Tag**: [total\_members](/themes/helpers/data/total_members/), **Description**: Outputs the number of members, rounded and humanised
- **Tag**: [total\_paid\_members](/themes/helpers/data/total_paid_members/), **Description**: Outputs the number of paying members, rounded and humanised
- **Tag**: [url](/themes/helpers/data/url/), **Description**: The post URL, when inside the `post` scope
