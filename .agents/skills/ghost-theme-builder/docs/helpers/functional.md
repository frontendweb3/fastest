---
title: Functional Helpers
sidebarTitle: Overview
description: Functional helpers are used to work with data objects. Use this reference list to discover what each handlebars helper can do when building a custom Ghost theme.
---

- **Tag**: [foreach](/themes/helpers/functional/foreach/), **Description**: Loop helper designed for working with lists of posts
- **Tag**: [get](/themes/helpers/functional/get/), **Description**: Special block helper for custom queries
- **Tag**: [has](/themes/helpers/functional/has/), **Description**: Like `{{#if}}` but with the ability to do more than test a boolean
- **Tag**: [if](/themes/helpers/functional/if/), **Description**: Test very simple conditionals
- **Tag**: [is](/themes/helpers/functional/is/), **Description**: Check the context of the current route
- **Tag**: [match](/themes/helpers/functional/match/), **Description**: Compare two values for equality
- **Tag**: [unless](/themes/helpers/functional/unless/), **Description**: The opposite of `{{#if}}`
