---
title: Utility Helpers
sidebarTitle: Overview
description: Utility helpers are used to perform minor, optional tasks. Use this reference list to discover what each handlebars helper can do when building a custom Ghost theme.
---

- **Tag**: [asset](/themes/helpers/utility/asset/), **Description**: Outputs cachable and cache-busting relative URLs to various asset types
- **Tag**: [block](/themes/helpers/utility/block/), **Description**: Used along with `{{contentFor}}` to pass data up and down the template hierarchy
- **Tag**: [body\_class](/themes/helpers/utility/body_class/), **Description**: Outputs dynamic CSS classes intended for the `<body>` tag
- **Tag**: [color\_to\_rgba](/themes/helpers/utility/color_to_rgba/), **Description**: Converts a color value into an RGBA string
- **Tag**: [concat](/themes/helpers/utility/concat/), **Description**: Concatenate and link multiple things together
- **Tag**: [contrast\_text\_color](/themes/helpers/utility/contrast_text_color/), **Description**: Returns a readable text color for a given background
- **Tag**: [encode](/themes/helpers/utility/encode/), **Description**: Encode text to be safely used in a URL
- **Tag**: [ghost\_head](/themes/helpers/utility/ghost_head_foot/) / [ghost\_foot](/themes/helpers/utility/ghost_head_foot/), **Description**: Outputs vital system information at the top and bottom of the document
- **Tag**: [link\_class](/themes/helpers/utility/link_class/), **Description**: Add dynamic classes depending on the currently viewed page
- **Tag**: [log](/themes/helpers/utility/log/), **Description**: In development mode, output data in the console
- **Tag**: [json](/themes/helpers/utility/json/), **Description**: Safely serialize values for inline JSON output
- **Tag**: [pagination](/themes/helpers/utility/pagination/), **Description**: Helper which outputs formatted HTML for pagination links
- **Tag**: [partials](/themes/helpers/utility/partials/), **Description**: Include chunks of reusable template code
- **Tag**: [plural](/themes/helpers/utility/plural/), **Description**: Output different text based on a given input
- **Tag**: [post\_class](/themes/helpers/utility/post_class/), **Description**: Outputs classes intended for your post container
- **Tag**: [prev\_post](/themes/helpers/utility/prev_next_post/) / [next\_post](/themes/helpers/utility/prev_next_post/), **Description**: Within the `post` scope, returns the URL to the previous or next post
- **Tag**: [reading\_time](/themes/helpers/utility/reading_time/), **Description**: Renders the estimated reading time for a post
- **Tag**: [search](/themes/helpers/utility/search/), **Description**: Output a working, pre-styled search button & icon
- **Tag**: [split](/themes/helpers/utility/split/), **Description**: Split a string into one or more iterable strings
- **Tag**: [translate](/themes/helpers/utility/translate/), **Description**: Output text in your site language (the backbone of i18n)
